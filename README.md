# JavaScript-ATM-Miniproject

## 📌 Project Description
This is a simple console-based ATM Simulation project developed using JavaScript. It allows users to perform basic ATM operations after successful PIN verification.

## 🚀 Features
- **PIN Verification:** Validates the user's PIN.
- **Check Balance:** Displays the available account balance.
- **Deposit:** Accepts a deposit amount and displays the updated balance.
- **Withdraw:** Allows users to withdraw money based on the available balance.
- **Error Handling:** Displays messages for invalid PINs and invalid menu choices.

## 🛠️ Technologies Used
- JavaScript
- Node.js
- prompt-sync

## 📚 JavaScript Concepts Used
- Variables (`let` and `const`)
- Data Type Conversion (`Number()`)
- Comparison Operators
- Conditional Statements (`if-else`)
- Switch Statements
- Template Literals
- Arithmetic Operators

## ⚙️ How to Run the Project

1. Clone the repository:
   ```bash
   git clone https://github.com/ramyabathala068/JavaScript-ATM-Miniproject.git
   ```

2. Navigate to the project folder:
   ```bash
   cd JavaScript-ATM-Simulation
   ```

3. Initialize npm:
   ```bash
   npm init -y
   ```

4. Install the required package:
   ```bash
   npm install prompt-sync
   ```

5. Run the JavaScript file:
   ```bash
   node miniproject.js
   ```
